# Portfolio Website

A small static portfolio project with a portfolio page and supporting images/documents.

## Contents

- `portfolio/` — website files and assets
- Image assets used by the page
- A PDF file included in the repository

## Technology

- HTML5
- CSS3
- Static images and document assets

## Run locally

1. Clone or download this repository.
2. Open the main HTML file inside the `portfolio/` directory in a modern browser.
3. Keep all images and linked assets in the same relative paths.

## Before publishing

Review the included PDF and images to ensure they are intended for public sharing. Replace outdated contact information, check mobile responsiveness, and add links to project repositories or a current resume if appropriate.
